# flucs_krehm
A collection of $\texttt{flucs}$ systems for solving the equations of the "kinetic reduced electron heating model" (KREHM) [1].

This package is a plugin for `flucs`. Installation instructions can be found at the [core flucs repository](https://github.com/flucs-code/flucs). 

[1] Zocco, A. & Schekochihin, A. A. 2011 Reduced fluid-kinetic equations for low-frequency dynamics, magnetic reconnection, and electron heating in low-beta plasmas. Phys. Plasmas 18, 102309.
