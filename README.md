# flucs_krehm
A collection of $\texttt{FLUCS}$ `systems` for systems of equations related to the 'kinetic reduced heating model' (KHREM, [[1](https://doi.org/10.1063/1.3628639), [2](https://doi.org/10.1016/j.cpc.2016.05.004)]).

This package is a plugin for `flucs`. Installation instructions can be found at the [core flucs repository](https://github.com/flucs-code/flucs).
